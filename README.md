A travel poster for Veldara, a village above the clouds where a waterfall pours off the cliff edge into the sea of mist below — drawn entirely in pure Python.

## The place

Veldara does not exist on any map. It is a small lantern-lit village
perched on a terraced cliff-top valley, high above a sea of clouds. Its
one landmark is the Skyfall: a waterfall that pours off the cliff edge
and vanishes into the cloud sea below. Evenings there are golden hour
that never quite ends — a low sun sinking toward the clouds, warm light
in every window, pines on the cliff top, birds crossing a violet sky.
A stay in Veldara promises exactly that: slow evenings above the
weather, watching the waterfall fall into nothing.

## Run it

```sh
python3 main.py
```

This writes a single 1024x1024 poster to `/output/entry.png`
(creating `/output` if needed). Pure Python 3 standard library only —
no network, no third-party packages, no randomness: the same bytes
come out every run.
