A travel poster for **Velmara**, a place that does not exist: a floating
isle above a glass sea, crowned by a crystal spire whose light guides
sailors home at sunset. Two moons, a sinking sun, waterfalls spilling off
the isle, and two small sailboats crossing the calm water.

## Run

```sh
python3 main.py
```

Writes a 1024x1024 PNG to `/output/entry.png` (set `OUTPUT_PATH` to
override the destination for local testing). Pure Python standard library
only — no dependencies, no network, fully deterministic: every run
produces the identical image.

## The poster

- **Place:** Velmara — Isle of the Glass Tides (invented)
- **Landmark:** the crystal spire, glowing at the centre of the floating isle
- **Palette:** indigo dusk melting into coral and gold at the horizon,
  deep teal glass sea
- **Type:** the place name set large in cream across the sky, with one
  quiet subtitle line beneath it
